# Phase 2 — การสอนงานและพัฒนาทักษะ

## ใช้งาน

1. HR สร้างหลักสูตรฉบับร่าง เพิ่มบทเรียนข้อความ URL หรืออัปโหลด PDF/MP4/WebM
2. เพิ่มข้อสอบและเกณฑ์สังเกตทักษะจริงก่อนเผยแพร่
3. เมนูเส้นทางการเรียน: สร้างเส้นทาง เลือกตำแหน่ง เพิ่มหลักสูตรที่เผยแพร่แล้ว แบ่งเป็นวันแรก/สัปดาห์แรก/ก่อนผ่านทดลองงาน
4. แต่ละขั้นระบุจำนวนวันหลังเริ่มเส้นทางที่ควรเรียนจบ เผยแพร่เพื่อมอบหมายอัตโนมัติ หรือหัวหน้ามอบหมายรายคน
5. พนักงานเรียนและสอบตามเดิม หากไม่ผ่านให้ทบทวนและสอบใหม่
6. หัวหน้าประเมินเช็กลิสต์ทุกข้อ พร้อมบันทึกสิ่งที่สังเกตหรือสิ่งที่ต้องฝึกเพิ่ม บันทึกผลระหว่างฝึกได้โดยยังไม่รับรอง
7. รับรองได้เมื่อผ่านข้อสอบและเกณฑ์จำเป็นครบทุกข้อ ห้ามประเมินตนเอง/ข้ามบริษัท/นอกลูกทีมโดยตรง
8. แจ้งเตือนในแอปแสดงใกล้ครบกำหนด 3 วัน เกินกำหนด สอบไม่ผ่าน และรอตรวจรับ แยกสถานะอ่านแล้วตามผู้ใช้

## เวอร์ชันและประวัติ

- หลักสูตรเผยแพร่แล้วแก้เนื้อหาไม่ได้ กดสร้างเวอร์ชันใหม่เพื่อคัดลอกบทเรียน ข้อสอบ และเช็กลิสต์เป็นฉบับร่าง
- ฉบับร่างแก้ข้อความบทเรียน นำข้อสอบ/เกณฑ์เดิมออก และเพิ่มรายการใหม่ได้
- เผยแพร่เวอร์ชันใหม่จะหยุดมอบหมายอัตโนมัติของเวอร์ชันเก่า และเพิ่ม enrollment ใหม่โดยไม่แก้คะแนน/การตรวจรับเดิม
- เส้นทางอ้างอิงเวอร์ชันหลักสูตรที่เลือกอย่างชัดเจน ไม่เปลี่ยนให้เองเมื่อเผยแพร่หลักสูตรใหม่
- หากเปลี่ยนเส้นทาง ให้หยุดมอบหมายอัตโนมัติของเส้นทางเก่า แล้วสร้างเส้นทางใหม่ ประวัติเดิมยังอยู่
- การมอบหมายซ้ำไม่รีเซ็ตคะแนนหรือกำหนดเดิมของหลักสูตรที่มีอยู่แล้ว

## ไฟล์ private

- ในเครื่องใช้ `data/uploads` (อยู่นอก public และถูก ignore จาก Git) ต้องสำรองโฟลเดอร์นี้พร้อมฐานข้อมูล
- บน Vercel ต้องสร้าง **Private Blob Store** และตั้ง `BLOB_READ_WRITE_TOKEN` เฉพาะโปรเจกต์/production
- หากยังไม่ตั้ง store จะปิดปุ่มอัปโหลดออนไลน์ ไม่ใช้ filesystem ชั่วคราวและไม่ลดความปลอดภัยไปใช้ public URL
- ขนาดสูงสุด 100 MB ต่อไฟล์ และ 250 MB ต่อบริษัท พื้นที่ Blob จริงยังอยู่ภายใต้โควตา/ค่าใช้จ่ายของผู้ให้บริการ
- อัปโหลดตรงไป object storage แบบ multipart เพื่อไม่ชนขีดจำกัด body ของ Vercel Function
- เซิร์ฟเวอร์ตรวจชนิด ขนาด และ magic bytes ของไฟล์ก่อนอนุญาตให้นำไปใช้ ไม่รับ HTML/SVG/executable
- ก่อนอ่านไฟล์ทุกครั้งต้องล็อกอินและผ่านสิทธิ์บริษัท/การมอบหมายบทเรียน รองรับ byte range สำหรับวิดีโอ
- ตรวจ header ไม่ใช่ antivirus; ควรเพิ่มการสแกน malware ก่อนรับเอกสารจากแหล่งที่ไม่เชื่อถือ
- PDF/วิดีโอยังไม่ถูก OCR/transcribe อัตโนมัติ ผู้ช่วยคู่มือค้นจากข้อความคำอธิบายบทเรียน
- ไฟล์ที่อัปโหลดค้าง/ถูกปฏิเสธยังต้องล้างผ่านผู้ดูแล storage ไม่มีการลบไฟล์อัตโนมัติที่อาจถูกใช้ในหลักสูตรเวอร์ชันเดิม

## Deploy

รัน `pnpm db:migrate` ก่อนเปิดแอป local; production ใช้ขั้นตอน DEPLOY_MIGRATE ที่มีอยู่
Migration มีเลขเวอร์ชัน checksum และ transaction lock รองรับฐานข้อมูลเดิมและป้องกัน build หลายตัวสร้าง schema พร้อมกัน
อย่าแก้ไฟล์ migration ที่ apply แล้ว ให้เพิ่มหมายเลขใหม่

Phase นี้ยังไม่รวมอีเมลเชิญ/กู้รหัสผ่าน และการส่งแจ้งเตือนภายนอกแบบ background ซึ่งเป็นงาน Phase 3/การเชื่อมต่อระบบจริง
